# PizzaShop PWA

Projeto React + TypeScript + Vite de uma pizzaria online, com loja, carrinho, checkout, acompanhamento de pedidos e painel administrativo.

## Executar

```bash
npm install
npm run mock-api
```

Em outro terminal:

```bash
npm run dev
```

Acesse o endereço exibido pelo Vite.

### Painel administrativo

- Usuário: `admin`
- Senha: `pizzashop123`

## Verificações

```bash
npm run lint
npm run build
npm test
```

A API usada no desenvolvimento é o `json-server` e fica em `http://localhost:3001`.
## Design v1
Esta versão aplica uma identidade visual de pizzaria artesanal moderna, mantendo a lógica e as funcionalidades da versão corrigida.
